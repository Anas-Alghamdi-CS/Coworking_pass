# Coworking Pass 🚀🇸🇦

**الشبكة الموحدة لمساحات العمل المشتركة في المملكة العربية السعودية (B2B2C Aggregator Platform).**

**Coworking Pass** هي منصة تجميعية رائدة تتيح للمستقلين والشركات الوصول إلى شبكة واسعة من مساحات العمل المشتركة (التابعة لعلامات تجارية متعددة مثل ريجس، زمكان، وغيرها) باشتراك وعضوية واحدة فقط! لم يعد المستخدم بحاجة لدفع اشتراكات منفصلة لكل مساحة؛ اشتراك واحد يفتح لك أبواب العمل من أي مدينة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **التصميم وتجربة المستخدم (UI/UX):** Figma
- **واجهات المستخدم (Frontend):** Next.js و Tailwind CSS (مفصولة في مجلد مستقل)
- **الخوادم وقواعد البيانات (Backend):** Next.js API Routes مع PostgreSQL
- **الأنظمة الأساسية:** نظام QR Code ذكي لتسجيل الحضور، ومحرك مالي لتوزيع الأرباح للشركاء (Revenue Sharing).

---

## 📜 دليل أوامر جيت هب للفريق (Git Guide)

مرحباً بك في فريق التطوير! يرجى الالتزام بهذه الأوامر لضمان عدم تعارض الأكواد:

### 1. سحب المشروع للمرة الأولى
افتح موجه الأوامر (Terminal) في جهازك واكتب الأوامر التالية:

```bash
# سحب كود المشروع من مستودع المنظمة
git clone https://github.com/Coworking-Pass-Team/Coworking_pass.git

# الدخول إلى مجلد المشروع
cd Coworking_pass

# سحب أحدث التعديلات لفرع التطوير
git checkout develop
git pull origin develop
```

### 2. كيف تبدأ العمل على مهمة جديدة؟
**ممنوع الرفع المباشر** على فرع `develop` أو `main`. لبرمجة مهمة جديدة اتبع التالي:

```bash
# تأكد أنك في فرع التطوير ومُحدّث
git checkout develop
git pull origin develop

# أنشئ فرعاً جديداً باسم مهمتك (مثلاً برمجة شاشة الشركاء)
git checkout -b feature/partner-dashboard
```

### 3. تشغيل المشروع برمجياً (بيئة التطوير)

**لفريق الواجهات (Frontend):**
```bash
# الدخول لمجلد الواجهات
cd frontend
# تثبيت المكتبات (أول مرة فقط)
npm install
# تشغيل خادم التطوير
npm run dev
```

**لفريق قواعد البيانات والسيرفر (Backend):**
```bash
# الدخول لمجلد الباك إند
cd backend
# تثبيت المكتبات
npm install
# تشغيل السيرفر
npm run dev
```

### 4. كيف ترفع الكود بعد إنجاز المهمة؟

```bash
# حفظ جميع التعديلات
git add .
# كتابة رسالة واضحة توضح ما قمت ببرمجته
git commit -m "feat: بناء الواجهة الرئيسية للشركاء Partner Dashboard"
# رفع الكود إلى جيت هب
git push origin feature/partner-dashboard
```
**ماذا بعد الرفع؟** 
اذهب إلى موقع جيت هب، وافتح طلب دمج (Pull Request) لفرع `develop`. الإدارة ستقوم بمراجعة كودك والموافقة عليه.
