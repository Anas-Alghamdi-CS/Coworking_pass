# Coworking Pass 🚀

**عضوية واحدة تفتح مساحات عمل مشتركة متعددة - نجمعها في منصة واحدة.**

---

## 🛠 الأدوات والتقنيات المستخدمة (Tech Stack)
- **التصميم (UI/UX):** Figma
- **الواجهات الأمامية (Frontend):** Next.js مع Tailwind CSS (مجلد مستقل)
- **الواجهات الخلفية (Backend):** Next.js لبرمجة مسارات الـ API (مجلد مستقل)
- **قاعدة البيانات (Database):** PostgreSQL

---

## 📚 دليل فريق العمل (Git Guide)

هذا القسم مخصص للفرق لمعرفة كيفية سحب المشروع ورفع التحديثات.

### 1. سحب المشروع لأول مرة
افتح الـ Terminal في جهازك ونفذ الأوامر التالية بالترتيب:

```bash
# سحب نسخة من المشروع إلى جهازك
git clone https://github.com/Coworking-Pass-Team/Coworking_pass.git

# الدخول إلى مجلد المشروع
cd Coworking_pass

# الانتقال لفرع التطوير (develop) لأن العمل لا يكون على الـ main
git checkout develop
```

### 2. كيف تفتح فرع (Branch) لمهمتك الخاصة؟
يُمنع تماماً رفع الكود مباشرة على فرع `develop` أو `main`. يجب على كل مبرمج فتح فرع خاص بمهمته.

مثال إذا كنت في فريق الواجهات ومهمتك صفحة الدخول:

```bash
# التأكد أنك متواجد في فرع التطوير الأساسي
git checkout develop

# سحب أحدث أكواد الفريق من السيرفر لتجنب التعارض
git pull origin develop

# إنشاء فرع جديد خاص بمهمتك والانتقال إليه
git checkout -b feature/front-login
```

### 3. الدخول لمجلدات المشروع والبدء بالبرمجة

**لفريق الواجهات (Frontend):**
```bash
# الدخول لمجلد الواجهات
cd frontend

# تثبيت المكتبات والحزم اللازمة (تنفذ أول مرة فقط)
npm install

# تشغيل المشروع للمعاينة
npm run dev
```

**لفريق الـ Backend:**
```bash
# الدخول لمجلد الباك إند
cd backend

# تثبيت المكتبات والحزم
npm install

# تشغيل السيرفر
npm run dev
```

### 4. كيف ترفع شغلك بعد الانتهاء من المهمة؟

```bash
# تحديد وحفظ جميع التعديلات التي قمت بها
git add .

# توثيق التعديلات برسالة توضح ما فعلته
git commit -m "feat: إتمام صفحة تسجيل الدخول"

# رفع فرعك إلى موقع GitHub
git push origin feature/front-login
```
بعدها اذهب إلى موقع GitHub، وافتح طلب دمج (Pull Request) ليقوم القائد بمراجعته واعتماده.
