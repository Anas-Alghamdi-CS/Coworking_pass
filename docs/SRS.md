# وثيقة متطلبات النظام (SRS) - Coworking Pass

هذه الوثيقة مخصصة لفرق العمل (UI/UX, Frontend, Backend) لفهم وظائف النظام، رحلة المستخدم، والمتطلبات بالتفصيل.

## 1. أنواع المستخدمين (User Roles)
النظام يحتوي على 4 أنواع من المستخدمين:
1. **الزائر (Guest):** يمكنه تصفح الموقع ورؤية مساحات العمل المتاحة، ولكنه لا يستطيع الحجز.
2. **المستخدم الفرد (Individual):** شخص مستقل يمتلك حساباً، يمكنه حجز مقاعد العمل (Hot Desks) لنفسه، ورؤية سجل حجوزاته.
3. **مستخدم المؤسسات (Organization):** حساب للشركات، يتيح حجز مساحات أكبر (مثل غرف الاجتماعات أو المكاتب المغلقة)، أو شراء باقات دخول لموظفيهم.
4. **مدير النظام (Admin):** الإدارة العليا للمنصة، يمتلك لوحة تحكم لإضافة/حذف مساحات العمل، إدارة المستخدمين، ومتابعة الحجوزات.

## 2. المتطلبات الوظيفية (Functional Requirements)
* **نظام الحسابات:** تسجيل دخول مخصص مع تحديد نوع الحساب (أفراد / مؤسسات).
* **تصفح المساحات:** عرض مساحات العمل وتصنيفها (مقعد فردي، غرفة اجتماعات).
* **إدارة الحجوزات:** حجز المقاعد أو الغرف، وإلغائها وإدارتها.
* **الملف الشخصي:** لوحة تحكم تعرض الحجوزات الحالية والسابقة.

## 3. قصص المستخدمين (User Stories)
* **كـ فرد:** أريد حجز مقعد في مساحة عمل قريبة مني اليوم، لكي أنجز عملي بهدوء.
* **كـ مؤسسة:** أريد حجز غرفة اجتماعات مجهزة لـ 5 أشخاص، لكي أعقد اجتماعاً مع العميل.
* **كـ مدير (Admin):** أريد رؤية إجمالي حجوزات اليوم، لكي أتأكد من سير العمل بشكل صحيح.

## 4. رحلة المستخدم (User Flow)
**تسلسل خطوات استخدام النظام:**
1. **الصفحة الرئيسية:** يرى المستخدم نبذة عن المنصة (أفراد ومؤسسات).
2. **صفحة المساحات:** يتصفح الكروت، يختار مساحة تناسبه.
3. **تأكيد الحجز (Booking):** يتم الحجز وتسجيله باسم الفرد أو المؤسسة.
4. **صفحة حجوزاتي (Dashboard):** تظهر تفاصيل الحجز للمستخدم.
