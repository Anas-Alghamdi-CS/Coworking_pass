# وثيقة متطلبات النظام (SRS) - Coworking Pass

هذه الوثيقة مخصصة لفرق العمل (UI/UX, Frontend, Backend) لفهم وظائف النظام بشكل مفصل.

## 1. أنواع المستخدمين وشخصياتهم (User Roles & Personas)
في منصتنا، نستهدف شخصيات (Personas) معينة لنوفر لهم أفضل تجربة:
* **بيرسونا 1 (المستقل - Freelancer):** "أحمد، 26 سنة، مبرمج مستقل". يحتاج إلى مكان هادئ للعمل وتغيير الروتين اليومي، ويفضل الحجز اليومي المرن.
* **بيرسونا 2 (المؤسسة - Startup):** "سارة، 32 سنة، مديرة شركة ناشئة". فريقها يعمل عن بعد، لكنها تحتاج لغرفة اجتماعات مرة بالأسبوع، وتفضل الحجز الشهري أو السنوي للغرف.

بناءً على ذلك، لدينا 4 أنواع للمستخدمين:
1. **الزائر (Guest):** يتصفح الموقع والمساحات فقط.
2. **المستخدم الفرد (Individual):** يمتلك حساباً ويحجز مقاعد العمل.
3. **مستخدم المؤسسات (Organization):** حساب شركات لحجز الغرف الكبيرة أو مكاتب كاملة.
4. **مدير النظام (Admin):** لإدارة المنصة بالكامل.

## 2. قصص المستخدمين (User Stories)
* **كـ زائر:** أريد أن أتصفح مساحات العمل المتاحة وأرى أسعارها وصورها، لكي أقرر إذا كانت تناسبني للتسجيل أم لا.
* **كـ زائر:** أريد أن تكون عملية التسجيل وإنشاء الحساب سريعة، لكي أتمكن من الحجز فوراً.
* **كـ فرد:** أريد حجز مقعد لمدة (يوم، شهر، أو سنة)، لكي أعمل براحة بالمدة التي تناسبني.
* **كـ فرد:** عندما أجد المساحة التي أريدها محجوزة، أريد معرفة متى ستفرغ وأفعل خيار "الحجز التلقائي/الانتظار"، لكي أضمن مقعدي فور خروج الشخص الحالي.
* **كـ مؤسسة:** أريد حجز غرفة اجتماعات لفريقي وتحديد تاريخ ووقت الدخول، لكي نعقد اجتماعنا الأسبوعي أو الشهري.
* **كـ مستخدم مسجل:** أريد الدخول لصفحة "حجوزاتي" لرؤية حجوزاتي السابقة والنشطة، لكي أستطيع إلغاء الحجز إن اضطررت لذلك.

## 3. رحلة المستخدم (User Flow)
**الرحلة خطوة بخطوة:**
1. **الاستكشاف:** يدخل المستخدم الصفحة الرئيسية (Home)، يرى قسم "اكتشف مساحات العمل"، ويتنقل بين كروت المساحات.
2. **التفاصيل:** يضغط على بطاقة مساحة معينة، يرى تفاصيلها (الموقع، السعر، الصور، والتقييم إن وجد).
3. **القرار (الحجز أو الانتظار):** 
   - إذا كانت المساحة متاحة: يختار خطة الدفع (يومي/شهري/سنوي) ويضغط "تأكيد الحجز".
   - إذا كانت محجوزة: يرى المؤقت الزمني، ويضغط زر "أضفني لقائمة الانتظار/الحجز التلقائي".
4. **المصادقة (Auth):** النظام يطلب منه تسجيل الدخول أو إنشاء حساب لإتمام العملية.
5. **الإدارة:** يتم توجيه المستخدم للوحة التحكم (Dashboard) لرؤية حالة حجزه (مؤكد أو قيد الانتظار).
