# وثيقة متطلبات النظام (SRS) - Coworking Pass

هذه الوثيقة مخصصة لفرق العمل (UI/UX, Frontend, Backend) لفهم وظائف النظام، رحلة المستخدم، والمتطلبات بالتفصيل.

## 1. أنواع المستخدمين (User Roles)
النظام يحتوي على 4 أنواع من المستخدمين:
1. **الزائر (Guest):** يمكنه تصفح الموقع ورؤية مساحات العمل المتاحة.
2. **المستخدم الفرد (Individual):** شخص مستقل يمكنه حجز مقاعد العمل (باليوم، بالشهر، أو بالسنة).
3. **مستخدم المؤسسات (Organization):** حساب للشركات، يتيح حجز مساحات أو غرف اجتماعات، أو شراء باقات دخول لموظفيهم.
4. **مدير النظام (Admin):** الإدارة العليا للمنصة لإدارة المساحات والمستخدمين.

## 2. المتطلبات الوظيفية (Functional Requirements)
* **نظام الحسابات:** تسجيل دخول مخصص (أفراد / مؤسسات).
* **تصفح المساحات:** عرض مساحات العمل وتصنيفها مع عرض الأسعار (يومي، شهري، سنوي).
* **إدارة الحجوزات المتقدمة:**
  - القدرة على الحجز بـ 3 أنواع: **يومي، شهري، سنوي**.
  - **مؤقت التوفر (Countdown):** إذا كانت المساحة محجوزة، يرى المستخدم عداداً يوضح (الوقت المتبقي لتصبح المساحة فارغة بناءً على موعد انتهاء الحجز الحالي).
  - **طابور الانتظار والحجز التلقائي (Auto-Booking):** يمكن للمستخدم تفعيل زر "حجز تلقائي"، ليقوم النظام بحجز المساحة له فور انتهاء حجز الشخص الحالي مباشرة.
* **الملف الشخصي:** لوحة تحكم تعرض الحجوزات الحالية والسابقة وقائمة الانتظار.

## 3. قصص المستخدمين (User Stories)
* **كـ فرد:** أريد حجز مقعد لمدة (شهر)، لكي أعمل براحة دون الحاجة للتجديد اليومي.
* **كـ فرد:** عندما أجد المساحة محجوزة، أريد معرفة متى ستفرغ وأفعل "الحجز التلقائي"، لكي أضمن مقعدي فور خروج الشخص الحالي.
* **كـ مؤسسة:** أريد حجز مساحة عمل لفرقي لمدة (سنة) كاملة.

## 4. رحلة المستخدم (User Flow)
1. **صفحة المساحات:** يتصفح الكروت، يرى حالة المساحة (متاحة أو محجوزة).
2. **تأكيد الحجز أو الانتظار:** 
   - إذا كانت **متاحة**: يختار (يومي، شهري، سنوي) ويتم الحجز.
   - إذا كانت **محجوزة**: يرى الوقت المتبقي ويضغط (تفعيل الحجز التلقائي).
3. **التنبيهات:** يصل للمستخدم إشعار عند نجاح حجزه التلقائي فور شغور المساحة.
