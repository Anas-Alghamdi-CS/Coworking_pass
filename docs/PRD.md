# وثيقة متطلبات المنتج (PRD) - Coworking Pass

## 1. نظرة عامة على المنتج (Overview)
**Coworking Pass** هي منصة مجمّعة (Aggregator) تهدف إلى توفير "عضوية واحدة" تتيح للمستخدمين الدخول إلى مساحات عمل مشتركة متعددة، بدلاً من الارتباط باشتراك شهري أو سنوي مع مساحة عمل واحدة فقط.

## 2. المشكلة والحل
* **المشكلة:** العاملون عن بُعد والمستقلون يشعرون بالملل من العمل في نفس المكان يومياً، والاشتراك في عدة مساحات عمل مكلف جداً.
* **الحل:** اشتراك أو نظام حجز مرن عبر منصة واحدة يفتح للمستخدم أبواب مساحات عمل مختلفة في المدينة.

## 3. المنافسون والميزة التنافسية (Competitors & USP)
* **المنافسون العالميون:** منصات مثل Deskpass و Croissant.
* **المنافسون المحليون:** الاشتراكات المباشرة مع مساحات العمل الفردية.
* **الميزة التنافسية (USP):** 
  - **المرونة (Flexibility):** العمل في منطقة مختلفة كل يوم حسب الحاجة.
  - **التوفير (Cost-effective):** اشتراك موحد أو دفع مرن يغني عن الدفع لعدة مساحات.
  - **الاستكشاف (Discovery):** مساعدة المستخدمين على إيجاد بيئات عمل وتطوير علاقات (Networking) جديدة.

## 4. نطاق العمل: النسخة الأولية (MVP Scope)
لضمان إطلاق سريع وناجح وفق منهجية Agile، النسخة الأولى (MVP) ستتضمن فقط:
1. **نظام المصادقة (Auth):** تسجيل حساب جديد، وتسجيل الدخول.
2. **الاستكشاف (Browse Spaces):** واجهة تعرض مساحات العمل المتاحة (صورة، اسم، موقع، السعر، المقاعد المتاحة).
3. **نظام الحجز (Booking):** القدرة على حجز مقعد، وإلغاء الحجز إن لزم الأمر.
4. **الملف الشخصي (User Dashboard):** صفحة خاصة للمستخدم تعرض حجوزاته القادمة والسابقة.

## 5. ميزات خارج النطاق حالياً (Out of Scope for MVP)
*(تؤجل لمرحلة التطوير الثانية Sprint 2)*
* نظام دفع إلكتروني متكامل (بوابات الدفع مثل Moyasar أو Stripe).
* لوحة تحكم خاصة لأصحاب مساحات العمل (Partner Dashboard) لإضافة وتعديل مساحاتهم بأنفسهم.
* تطبيق مخصص للهواتف الذكية (iOS & Android).
* نظام التقييم والمراجعات (Reviews).

## 6. المتطلبات التقنية المعتمدة
* **الواجهات الأمامية والخلفية:** Next.js (Full-stack)
* **التصميم وتنسيق الواجهات:** Figma & Tailwind CSS
* **قاعدة البيانات:** PostgreSQL
* **إدارة المشروع:** GitHub (نظام الفروع main و develop) وملف Backlog.
